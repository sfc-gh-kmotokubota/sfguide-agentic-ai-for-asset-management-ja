# プライベートエクイティ コパイロット デモシナリオ

**エージェント**: `AM_private_equity_copilot`
**ペルソナ**: Alexandra Chen（PEポートフォリオマネージャー）
**デモ画面**: Snowflake CoWork / Snowflake Intelligence
**使用スキル**: deal-pipeline-screening, competitive-intelligence, equity-research-report, investment-memo-generation, pdf-report-generation, executive-briefing, concentration-risk-assessment

---

## エージェント設定

### 主なツール
- **Cortex Analyst（構造化データ）**: PE案件パイプライン、ポートフォリオ会社財務、バリュークリエーション指標
- **Cortex Search（ドキュメント）**: ブローカーリサーチ、SEC提出書類、業界レポート、エンゲージメントノート
- **カスタムツール**: PDF生成（投資家向け資料）、M&Aシミュレーション

## シナリオ 1: ディールソーシングとスクリーニング

### コンテキスト
PEファンドが新規投資対象を探しています。特定のセクターと地域の基準を満たす企業を特定する必要があります。

### ステップ 1-1: セクター/地域スクリーニング

**プロンプト（ユーザー）**:
```
ソフトウェアとテクノロジーセクターで、売上成長率20%以上、EBITDAマージン15%以上の
企業をスクリーニングしてください。北米に絞り、過去3年間のトレンドも確認してください。
```

**期待される応答フロー**:
1. SAM_FUNDAMENTALS_VIEW から財務メトリクスを照会
2. 成長率・マージン基準でフィルタリング
3. 地域フィルター（北米）を適用
4. 過去3年間のトレンド分析
5. スコアリングとランキング付き候補リストを返す

**トーキングポイント**:
- 「複数のデータソースから瞬時にスクリーニング。従来は数日かかる作業が秒単位で完了」
- 「財務基準だけでなく、トレンド分析も自動的に含む」

---

### ステップ 1-2: 競合ポジショニング分析

**プロンプト（ユーザー）**:
```
スクリーニング結果の上位3社について、競合他社との比較分析をお願いします。
特に市場シェア、製品差別化、顧客獲得コストの観点から評価してください。
```

**期待される応答フロー**:
1. SEC提出書類からの競合他社情報を検索
2. SAM_FUNDAMENTALS_VIEW で財務比較
3. ブローカーリサーチから市場ポジション分析
4. 差別化要因の評価サマリーを生成

**トーキングポイント**:
- 「SEC提出書類をリアルタイムで解析し、競合ポジショニングを客観的に評価」
- 「アナリストの見解と実際の財務データを組み合わせた多角的分析」

### ステップ 1-3: 投資メモの生成

**プロンプト（ユーザー）**:
```
最有力候補の企業について、投資委員会向けの投資メモを作成してください。
財務サマリー、主要リスク、バリュークリエーション仮説を含めてください。
```

**期待される応答フロー**:
1. 財務データ（成長、収益性、バランスシート）を統合
2. ブローカーリサーチと決算書から経営陣コメントを取得
3. リスク要因（市場、競合、規制）を特定
4. バリュークリエーションの仮説（オペレーション改善、M&A、地理的拡大）を構築
5. 構造化された投資メモを生成

**期待される投資メモ構成**:
```
## 投資サマリー
- 企業概要と投資テーゼ
- 主要な財務指標（前年比）

## バリュークリエーション仮説

2. 隣接市場への拡大: アドレスブルマーケット
3. 製品ポートフォリオ拡充: クロスセル機会

## 主要リスクと緩和策
- 技術リスク: 製品陳腐化リスクと対策

- 規制リスク: データプライバシー規制の影響

## 財務予測（保守的/ベース/楽観的シナリオ）

## 推奨アクション
```

## シナリオ 2: ポートフォリオ会社の健全性評価

### コンテキスト
既存のポートフォリオ会社の四半期業績をレビューし、バリュークリエーション計画の進捗を確認します。

### ステップ 2-1: 四半期業績レビュー

**プロンプト（ユーザー）**:
```
SAM Growth Equity I ファンドのポートフォリオ会社について、
Q3 2024の業績をバジェットと前年同期比で比較してください。
KPIダッシュボードを提供してください。
```

**期待される応答フロー**:
1. SAM_EXECUTIVE_VIEW から四半期業績データを取得
2. バジェット対比分析（各KPIの達成率）
3. 前年同期比（YoY）トレンド
4. セクター別パフォーマンス分解
5. サマリーダッシュボード表形式で返す

**期待される出力テーブル**:
```
| 企業名 | 売上 (実績) | 売上 (予算) | 達成率 | YoY成長率 | EBITDA | ステータス |
|--------|-----------|-----------|------|---------|-------|---------|
| TechCo A | $12.3M | $11.8M | 104% | +28% | $3.2M | 🟢 超過 |
| SoftCo B | $8.1M | $9.2M | 88% | +12% | $1.4M | 🔴 未達 |
| DataCo C | $5.7M | $5.5M | 104% | +35% | $1.1M | 🟢 超過 |
```

---

### ステップ 2-2: アンダーパフォーマー調査

**プロンプト（ユーザー）**:
```
SoftCo Bがバジェットを下回っています。
決算説明会のトランスクリプトと最新のブローカーリサーチから
原因を調査し、是正アクションを提案してください。
```

**期待される応答フロー**:
1. 決算説明会トランスクリプトを検索・分析
2. 管理チームのコメントから問題点を特定
3. ブローカーリサーチから業界トレンドと比較
4. 根本原因分析（市場要因 vs 社内要因）
5. 是正アクション案を提示

**期待されるアウトプット例**:
```
## SoftCo B 業績未達分析

### 根本原因
**主な要因（社内）**:
- セールスサイクルの長期化: 大型案件の意思決定遅延
- エンタープライズ転換: SMBからエンタープライズへの移行コスト

**市場要因**:
- ソフトウェア支出の慎重化: 業界全体で▲8%
- 競合他社の価格引き下げによるARPU低下

### 推奨アクション
1. **短期**: パイプライン加速 - 四半期末インセンティブの設計
2. **中期**: プロダクトポジショニング見直し - エンタープライズ機能強化
3. **長期**: 組織再編 - エンタープライズ専門セールスチームの設立
```

## シナリオ 3: デューデリジェンス支援

### コンテキスト
新規投資候補に対するデューデリジェンスプロセスを支援します。

### ステップ 3-1: 財務デューデリジェンス

**プロンプト（ユーザー）**:
```
HealthTech社の財務デューデリジェンスを実施してください。
SEC提出書類から過去5年間の財務トレンド、収益の質、
キャッシュコンバージョンを分析してください。
```

**期待される応答フロー**:
1. SAM_SEC_FINANCIALS_VIEW から5年間の財務データを取得
2. 収益の質分析（会計上の選択、一時的項目の識別）
3. キャッシュフロー分析（FCF、運転資本トレンド）
4. 負債構造と流動性分析
5. 同業他社ベンチマーク

**プロンプト（ユーザー）**:
```
決算説明会で経営陣がどのような戦略的メッセージを発信しているか確認し、
一貫性があるか評価してください。
```

**期待される応答**:
- 過去8四半期の決算説明会からメッセージを抽出
- 戦略的一貫性のスコアリング
- メッセージと実際の業績の乖離点を特定

## デモのポイント

### ビジネス価値のメッセージ

| 従来の課題 | SAM PEコパイロットの解決策 |
|----------|------------------------|
| デューデリジェンスに数週間かかる | 財務分析が数分で完了 |
| 複数システムからのデータ集約が困難 | 単一の会話インターフェースで全データにアクセス |
| レポート作成に多大な時間を消費 | プロフェッショナルなPDFを即座に生成 |
| ポートフォリオ監視の見落としリスク | リアルタイムKPIアラートと異常検出 |
| 競合情報の収集に時間がかかる | SEC提出書類から自動的に競合情報を抽出 |

### 主な差別化ポイント

1. **速度**: デューデリジェンスプロセスの大幅な短縮
2. **網羅性**: 14,000以上の証券データと70以上のドキュメントテンプレートを活用
3. **一貫性**: 標準化されたプロセスによる投資判断の質の向上
4. **スケーラビリティ**: 少人数チームでより多くの案件を効率的に処理
