# プライベートクレジット コパイロット デモシナリオ

**エージェント**: `AM_private_credit_copilot`
**ペルソナ**: Michael Torres（プライベートクレジットPM）
**デモ画面**: Snowflake CoWork / Snowflake Intelligence
**使用スキル**: covenant-monitoring, credit-portfolio-review, rate-sensitivity-analysis, deal-pipeline-screening, credit-risk-calculator, concentration-risk-assessment, pdf-report-generation

---

## エージェント設定

### 主なツール
- **Cortex Analyst（構造化データ）**: ローンポートフォリオ、コベナンツ指標、借り手財務状況、ディールパイプライン
- **Cortex Search（ドキュメント）**: コベナンツ契約書、ローン契約、エンゲージメントノート、業界リサーチ
- **MLモデル統合**: クレジットリスクスコアリング（XGBoostモデル）
- **カスタムツール**: PDF生成（投資家向けレポート）

## シナリオ 1: コベナンツ監視と違反アラート

### コンテキスト
プライベートクレジットポートフォリオのコベナンツコンプライアンスを監視し、潜在的な違反リスクをプロアクティブに特定します。

### ステップ 1-1: コベナンツ監視ダッシュボード

**プロンプト（ユーザー）**:
```
SAM Direct Lending Fund I のすべての借り手について、
現在のコベナンツコンプライアンス状況を確認してください。
特にレバレッジ比率とインタレストカバレッジ比率が閾値に近い借り手を特定してください。
```

**期待される応答フロー**:
1. SAM_MIDDLE_OFFICE_VIEW からコベナンツメトリクスを取得
2. 各借り手のレバレッジ比率（Debt/EBITDA）を計算
3. インタレストカバレッジ比率（EBITDA/Interest）を評価
4. 閾値との乖離幅でカラーコーディング
5. リスクランキング付きダッシュボードを生成

**期待されるダッシュボード出力**:
```
| 借り手 | ローン残高 | レバレッジ比率 | 閾値 | ICR | 閾値 | ステータス |
|--------|----------|------------|-----|-----|-----|---------|
| Alpha Industries | $45M | 5.2x | 5.5x max | 2.3x | 2.0x min | 🟡 要注意 |
| Beta Holdings | $32M | 3.8x | 4.5x max | 3.1x | 2.0x min | 🟢 正常 |
| Gamma Corp | $28M | 5.4x | 5.5x max | 2.1x | 2.0x min | 🔴 違反リスク高 |
```

---

### ステップ 1-2: 違反リスク借り手の詳細調査

**プロンプト（ユーザー）**:
```
Gamma Corpのコベナンツ違反リスクが高いようです。
最新の財務諸表、ローン契約のコベナンツ条件、
これまでのエンゲージメント履歴を確認し、状況を詳しく分析してください。
```

**期待される応答フロー**:
1. ローン契約書から正確なコベナンツ条件を検索
2. 最新財務諸表（直近2四半期）のトレンド分析
3. エンゲージメントノートから過去のコミュニケーション履歴を確認
4. 違反リスクの根本原因分析
5. 是正アクションオプションを提示

**期待されるアウトプット例**:
```
## Gamma Corp コベナンツリスク分析

### 現在の財務状況
- 売上成長率: +3%（業界平均+12%を大幅に下回る）
- EBITDA: 前四半期比 ▲18%（主に原材料コスト上昇）
- 純負債: 変化なし（負債削減なし）

### コベナンツ条件（ローン契約より）
- レバレッジ比率上限: 5.5x（現在: 5.4x、余裕: 0.1x）
- ICR下限: 2.0x（現在: 2.1x、余裕: 0.1x）
- 次回測定日: 2024年12月31日

### トレンド予測
EBITDAが現在のペースで低下した場合、次回測定でコベナンツ違反の可能性が高い

### 推奨是正アクション
1. **即時**: 借り手との緊急ミーティングを設定
2. **短期**: ウェーバー条件の交渉（追加手数料、金利引き上げ）
3. **中期**: 改善計画（EBITDA回復ロードマップ）の要求
```

## シナリオ 2: クレジットポートフォリオの包括的レビュー

### ステップ 2-1: ポートフォリオ全体の健全性チェック

**プロンプト（ユーザー）**:
```
SAM Direct Lending Fund I のポートフォリオ全体のクレジット健全性をレビューしてください。
業種別の集中リスク、格付けトレンド、過去12ヶ月の借り手パフォーマンスを含めてください。
```

**期待される応答フロー**:
1. SAM_COMPLIANCE_VIEW からポートフォリオ構成データを取得
2. 業種別集中度分析（上位5業種）
3. 内部信用格付けトレンド（格上げ/格下げ件数）
4. NPLレート（不良債権比率）の推移
5. 既存コミットメントの加重平均スプレッドと収益性

**期待されるサマリー出力**:
```
## ポートフォリオ健全性サマリー

### 規模と構成
- 総ローン残高: $480M（22借り手）
- 加重平均スプレッド: SOFR + 5.2%
- 加重平均デュレーション: 3.8年

### 集中リスク
- 最大業種: テクノロジー 28%（内部上限: 30%）
- 最大単一借り手: 9.4%（内部上限: 10%）
- ⚠️ ヘルスケアセクター 22%（上限: 25%）— 要監視

### 信用質
- 正常: 18件（82%）
- 要注意: 3件（14%）
- 不良: 1件（4%）
```

### ステップ 2-2: 借り手の財務健全性の詳細評価

**プロンプト（ユーザー）**:
```
要注意カテゴリーの3社について、それぞれ詳細な財務分析を行い、
クレジットリスクスコアを計算してください。また、今後12ヶ月のデフォルトリスクを評価してください。
```

**期待される応答フロー**:
1. 各借り手の最新財務諸表を取得
2. 5つの財務指標（流動性、レバレッジ、収益性、成長性、カバレッジ）でスコアリング
3. MLクレジットリスクモデルを使用してデフォルト確率（PD）を計算
4. 業界ベンチマークとの比較
5. 12ヶ月デフォルトリスク評価

**トーキングポイント**:
- 「ML（機械学習）モデルが過去のデフォルトデータから学習し、より精度の高いリスク評価を提供」
- 「人間のアナリストでは見落としがちな複数変数の相関関係を自動的に分析」

## シナリオ 3: 金利感応度分析

**プロンプト（ユーザー）**:
```

```

**期待される応答フロー**:
1. ポートフォリオの固定/変動金利ミックスを分析

```

### ステップ 5-1: MLモデルによるデフォルト予測

**プロンプト（ユーザー）**:
```

今後12ヶ月のデフォルト確率（PD）を計算してください。
SHAPによる特徴量の重要度も確認したいです。
```

**期待される応答フロー**:
1. credit_risk_model.ipynb（ノートブック）のモデルを参照
2. 各借り手の財務データを特徴量として入力
3. XGBoostモデルでPD（確率）を計算
4. SHAP値でデフォルトリスクに最も寄与する要因を特定
5. ポートフォリオ全体のリスク分布を視覚化

**期待されるSHAP分析出力**:
```

## デモのポイント

### ビジネス価値のメッセージ

| 従来の課題 | SAM Private Credit Copilotの解決策 |
|----------|----------------------------------|
| コベナンツ監視が手動の定期チェックのみ | リアルタイムモニタリングとプロアクティブアラート |
| 複数のExcelシートでポートフォリオ管理 | 単一のAIインターフェースで全データにアクセス |

| 投資委員会レポート作成に多大な時間 | プロフェッショナルなPDFを即座に生成 |

1. **プロアクティブリスク管理**: コベナンツ違反を事前に予測し、早期対応を可能にする

3. **金利感応度分析**: 複数シナリオを即座に計算
4. **統合ワークフロー**: スクリーニングからレポーティングまで単一プラットフォームで完結
